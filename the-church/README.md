# The Church — Il videogioco su S. Andrea

**[Gioca gratis sul sito ufficiale](https://www.thechurchgame.it/)**

Un progetto di Giuseppe Passalacqua ambientato nel quartiere Sant’Andrea di Novara.

## Modalità
- Strade di S. Andrea: percorso arcade in 12 scenari.
- Quartiere: esplorazione con vista dall’alto.
- Duello classico: combattimenti uno contro uno.
- Prima persona: modalità 3D.

## Comandi
Il menu iniziale riporta i comandi per tastiera, touch e joypad. Collega il controller prima di giocare e premi un tasto perché il browser lo rilevi. I nomi e la disposizione dei pulsanti possono variare in base al controller.

## Avvio locale
Questi sono file web, non un programma Windows installabile. Per servirli localmente, con Python 3 installato:

```sh
python -m http.server 8000
```

Apri http://localhost:8000 nel browser. Per giocare senza configurazione usa il sito ufficiale.
